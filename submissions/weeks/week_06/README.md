# Week 06 — Does emergence have memory?

**Phase B — AI**

> When emergences cluster, is it a shared underlying cause or one emergence triggering the next?

## Concepts

- Shared cause (Cox-like): a latent field that favors some places and times
- Direct triggering (Hawkes-like): each emergence raises the rate nearby for a while
- History features: decaying summaries of recent nearby emergences, added as inputs
- Causality and leakage: features may only use the past, and must not reach across a held-out fold
- Time symmetry as a signature: shared causes have no arrow of time; triggering does

## Deliverable

An ablation: does knowing recent emergences improve held-out likelihood, and what can — and can't — this data decide?

## Notes

- Without longitude, the two mechanisms are hard to separate. A clearly argued 'the data cannot decide, and here is why' is a valid outcome.
